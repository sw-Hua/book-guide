# 注解格式与正反例

## 格式

每个单元两条：

```json
{
  "u012": {
    "bg": "背景 2–3 句，纯事实",
    "ex": "解释 2–4 句，说机关不说感想"
  }
}
```

- `bg`：60–140 字。谁、哪本书哪一卷、什么年代、术语原义。
- `ex`：80–180 字。这段在做什么、汉语读不出来的东西、与全书的接口。
- 原文里已经说清的，不要再写进 `bg` 或 `ex`。

## 反例（不要这样写）

**一、评价代替事实**
> 这段关于井蛙与夏虫的对话意味深长，蕴含着对认知局限的深刻洞察。

问题：`意味深长`、`深刻洞察` 是禁词；没有给任何可核查的信息。

**二、复述原文**
> 这段讲井蛙不能谈海、夏虫不能谈冰，说的是处境决定认知。

问题：读者刚读完，不需要再听一遍情节。

**三、读后感**
> 读到这里不禁让人反思，我们是不是也常常高估自己的能力。

问题：把读者该做的事替他做了，且带禁词。

**四、比喻讲概念**
> 随机性就像一位不请自来的客人。

问题：比喻会引入新歧义。解释概念要说清定义和来历。

**五、每条都接现实**
> 这在今天的股市中依然适用，比如最近的美股……

问题：一个概念只接一次现实，反复接会打断听感。

## 正例

```json
"u014": {
  "bg": "《庄子·秋水》写于战国中后期，秋水篇借河伯与北海若的七番问答展开。“虚”在这里不是空无，指所居之处；“时”指时令。井蛙、夏虫两句是并列的比喻。",
  "ex": "庄子用的不是修辞，是论证：认知的边界由处境划定，不由智力划定。他把“不能理解”归因于位置，而不是归因于笨。这一句常被当成骂人的话引用，原文里讲的却是限制的来源。"
}
```

好在三点：
1. `bg` 里每个事实都能查（年代、卷次、官职）。
2. `ex` 指出题眼落在哪一句，不说「意味深长」。
3. 末句说出这一句常被误读成什么，这是读者容易漏掉的。

```json
"u100": {
  "bg": "《世说新语·汰侈》记石崇与王恺争豪，两人都是西晋外戚，以奢靡相较。珊瑚树在当时由南海商路输入，属稀见之物。",
  "ex": "刘义庆写这场比富，落点在王恺“惘然自失”，不在珊瑚树本身。争的从来不是东西，是谁有资格定标准。"
}
```

好在 `ex` 只有两句，第二句把整节的机关说完了：写的是争胜，不是财富。

## 写之前问自己三个问题

1. 这段话里有没有读者不知道的**专名、年代、书目**？→ 写进 `bg`。
2. 作者的**反讽或转折**落在哪个字上？→ 写进 `ex`。
3. 我这句话，读者读完原文后能不能自己说出来？→ 能，就删掉。
