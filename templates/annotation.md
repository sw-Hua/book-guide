# 注解格式与正反例

## 格式

每个单元两条：

```json
{
  "u012": {
    "bg": "背景 2–3 句，纯事实",
    "ex": "解释 2–4 句，说机关不说感想"
  }
}
```

- `bg`：60–140 字。谁、哪本书哪一卷、什么年代、术语原义。
- `ex`：80–180 字。这段在做什么、汉语读不出来的东西、与全书的接口。
- 原文里已经说清的，不要再写进 `bg` 或 `ex`。

## 反例（不要这样写）

**一、评价代替事实**
> 梭伦与克罗伊斯的对话意味深长，蕴含着对人生无常的深刻洞察。

问题：`意味深长`、`深刻洞察` 是禁词；没有给任何可核查的信息。

**二、复述原文**
> 这段讲克罗伊斯问梭伦谁最快乐，梭伦回答说要看结局。

问题：读者刚读完，不需要再听一遍情节。

**三、读后感**
> 读到这里不禁让人反思，我们是不是也常常高估自己的能力。

问题：把读者该做的事替他做了，且带禁词。

**四、比喻讲概念**
> 随机性就像一位不请自来的客人。

问题：比喻会引入新歧义。解释概念要说清定义和来历。

**五、每条都接现实**
> 这在今天的股市中依然适用，比如最近的美股……

问题：一个概念只接一次现实，反复接会打断听感。

## 正例

```json
"u014": {
  "bg": "克罗伊斯是吕底亚末代国王，在位约前560至前546年，德尔斐神谕的著名供奉者。梭伦前594年任雅典执政官。会面见希罗多德《历史》第一卷第二十九至三十三节，两人年代对不上。",
  "ex": "“只有承蒙上苍垂怜从此能幸福以终的人，我们才能称之为幸福快乐”是整篇的题眼。塔勒布要的不是史料，是“到死才结算”这个计时器。他随后自己点破会面是虚构，先替考据派把话讲了。"
}
```

好在三点：
1. `bg` 里每个事实都能查（年代、卷次、官职）。
2. `ex` 指出题眼落在哪一句，不说「意味深长」。
3. 末句点出作者的自我防御动作，这是读者容易漏掉的。

```json
"u100": {
  "bg": "公园大道（Park Avenue）是曼哈顿上东区的高端住宅街，住户多为金融与法律界高层。",
  "ex": "马克的年薪五十万美元在统计上已属顶尖，却在自己楼里垫底。塔勒布把这件事写成样本问题，不是心理问题。"
}
```

好在 `ex` 只有两句，第二句把整节的机关说完了：这是抽样偏差，不是心态问题。

## 写之前问自己三个问题

1. 这段话里有没有读者不知道的**专名、年代、书目**？→ 写进 `bg`。
2. 作者的**反讽或转折**落在哪个字上？→ 写进 `ex`。
3. 我这句话，读者读完原文后能不能自己说出来？→ 能，就删掉。
